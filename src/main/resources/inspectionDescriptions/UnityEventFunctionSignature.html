Reports a method of a Unity class (a MonoBehaviour, ScriptableObject, Editor, EditorWindow, AssetPostprocessor) that looks like an event function but is not one, so Unity never calls it:
  • the name in another case: update, onTriggerEnter — the quick-fix renames it;
  • parameters of another type: OnTriggerEnter(Collision other) instead of OnTriggerEnter(Collider other) — the quick-fix writes the signature Unity calls. A message declared without its parameter (OnCollisionEnter()) is fine: Unity calls it that way as well.
