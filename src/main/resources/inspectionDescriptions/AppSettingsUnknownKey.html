Reports a key in appsettings*.json inside a section bound to a C# class (Configure<T>, GetSection(...).Get<T>(), AddOptions<T>().Bind(...)) that the class has no property for: a typo, or a value nothing reads. Keys are compared ignoring case, as the configuration binder does.

Weak: the configuration of a program is more than its classes, and a key may be read by another library or by hand.
