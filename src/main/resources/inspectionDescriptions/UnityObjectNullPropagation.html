Reports ?., ?? and ??= on a value of a type derived from UnityEngine.Object (components, game objects, scriptable objects, assets) in a Unity project.

Unity overloads == for these types: an object destroyed with Destroy compares equal to null while the C# object is still there. The null-conditional and null-coalescing operators do not call that overload, so a destroyed object passes them and the next access throws MissingReferenceException. Compare with null explicitly (if (target != null) target.Hit();) or use the implicit bool conversion (if (target)).
