Reports a string a Unity API takes as a name of the project that the project does not define:
  • a tag in CompareTag, tag == "…", FindWithTag, FindGameObjectsWithTag — not in Tags and Layers (ProjectSettings/TagManager.asset, plus the built-in tags); CompareTag throws on it;
  • a layer in LayerMask.NameToLayer, LayerMask.GetMask — NameToLayer gives -1;
  • a scene in SceneManager.LoadScene and its kin that is not in the scenes of the build (ProjectSettings/EditorBuildSettings.asset, by name or path);
  • an axis or button in Input.GetAxis, GetButton… — not in the Input Manager (ProjectSettings/InputManager.asset).
The same names are offered by the completion inside these strings.
