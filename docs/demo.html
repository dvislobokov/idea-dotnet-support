C# и .NET в той IDE, которая у вас уже открыта

Пишите, отлаживайте и тестируйте сервисы на .NET там же, где живёт остальной код команды. Без второй IDE и без смены привычек.

Одна IDE на весь стек

Сервисы на .NET рядом с фронтендом, Go и Python. Одни настройки, одни горячие клавиши, одно окно.

Работает в бесплатной IDEA

Все возможности, включая отладчик, доступны в IntelliJ IDEA Community.

Компилятор Microsoft внутри

Ошибки и исправления даёт Roslyn: тот же компилятор, который собирает ваш код.

Редактор, который дописывает за вас

Меньше набора и меньше переключений внимания: редактор предлагает готовые строки и находит ошибки до сборки.

  • Продолжение строки. Свойства, конструкторы и аргументы вызовов появляются серым текстом. Остаётся нажать Tab.
  • Готовые вызовы. Начните набирать имя, и редактор подставит вызов целиком и сам подключит нужное пространство имён.
  • Ошибки и исправления. Проблемы видны во всём решении, а Alt+Enter исправляет их в файле, проекте или везде сразу.

Отладчик, к которому не нужно привыкать

Стандартное окно Debug со всеми его возможностями. Причина ошибки находится быстрее, когда значения видны прямо в коде.

  • Остановка там, где нужно. Условия, счётчики попаданий и исключения выбранного типа.
  • Состояние перед глазами. Значения рядом с кодом, вычисление выражений, стек асинхронных вызовов.
  • Любой сценарий. Приложение, отдельный тест или уже работающий процесс.

Видно, какая строка расходует память

Запустите приложение, и рядом с кодом появятся измеренные значения: сколько памяти выделяет каждая строка.

  • Измерение, а не предположение. Данные снимаются с работающей программы, а не выводятся из текста кода.
  • Понятно, с чего начать. Доля строки в общем расходе показывает, что оптимизировать первым.
  • Без подготовки. Обычный запуск из IDE: без профилировщика и специальной сборки.

Решение целиком, а не папка с файлами

Проекты, зависимости и конфигурации показаны так, как их видит сборка. Сборка и запуск доступны в один клик.

  • Любой формат. .sln, .slnx и фильтры .slnf, несколько решений в одной папке.
  • Зависимости под контролем. Пакеты, проекты и анализаторы по каждой целевой платформе.
  • Сборка и запуск. Ошибки сборки со ссылками на код, профили запуска, окно Services.

Тесты и покрытие в одном окне

xUnit, NUnit, MSTest и TUnit: запуск, отладка и покрытие без командной строки.

  • Запуск от места в коде. Один тест, класс или только упавшие.
  • Покрытие на виду. В редакторе, по файлам и в дереве проекта.
  • Быстрый старт. Тестовый класс для выбранного типа создаётся из Alt+Enter.

Всё остальное тоже на месте

Повседневные задачи решаются из IDE, без терминала и сторонних утилит.

NuGet

Поиск, установка и обновление пакетов по всему решению, включая приватные источники.

EF Core

Миграции, обновление базы данных и SQL-скрипты из меню.

Мониторинг

Процессор, память и сборка мусора работающего приложения, снимки кучи и дампы.

Endpoints

Все маршруты API одним списком, запрос к любому из них в один клик.

Единый стиль кода

CSharpier или dotnet format по привычной комбинации клавиш.

Шаблоны

Заготовки файлов и типовых конструкций вместо однотипного кода вручную.

Сценарий демонстрации на 12 минут
  1. Открыть папку с решением. Панель Solution, зависимости по платформам.
  2. Запустить веб-проект из Services. Ссылка на адрес, окно Endpoints, запрос в .http.
  3. Набрать код. Свойство и конструктор серым текстом, WriteLi и Tab, лямбда в AddSingleton.
  4. Alt+Enter. Fix All in Solution, затем Shift+F6 на классе.
  5. Отладка. Остановка на исключении, Evaluate, Set Next Statement.
  6. Расход памяти. Show Allocations in Editor, Run, значения у строк.
  7. Тесты с покрытием. Unit Tests, Run with Coverage, Rerun Failed.
  8. NuGet. Поиск, установка, обновление пакетов решения.
  9. EF Core. Add Migration, статус миграций, Update Database.
  10. Мониторинг. Графики, два снимка кучи, memory dump.

Три шага до первой строки кода

  1. Установите инструменты

    Settings, .NET, .NET Tools. Нужны сервер языка и отладчик, остальное по желанию.

  2. Откройте папку с решением

    Панель проекта переключится на Solution. Если решений несколько, IDE спросит, какое загрузить.

  3. Работайте

    Подсветка и подсказки доступны сразу, полный анализ включается после загрузки решения. Состояние видно в статус-баре.
