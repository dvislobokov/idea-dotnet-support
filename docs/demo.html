Редактор, который понимает код

Семантику даёт компилятор Roslyn. Ошибки видны во всех файлах solution, а не только в открытом.

  • Серый текст по Tab. Авто-свойство, new(), параметры и тело конструктора, аргументы вызова, лямбда на месте делегата.
  • Alt+Enter. Исправления и рефакторинги Roslyn, Fix All по документу, проекту и solution.
  • Навигация. Объявление, реализации, иерархии типов и вызовов, декомпилированный код фреймворка.
  • Набор без ожидания. Postfix-шаблоны, Surround With, парные <> у generic работают, пока solution ещё грузится.

Отладчик без оговорок про лицензию

Собственный клиент протокола отладки поверх стандартного окна Debug. Работает и в бесплатной IDEA Community.

  • Точки останова. Условие, счётчик попаданий, сообщение в лог, остановка на исключениях по типу.
  • Выполнение. Шаги, Run to Cursor, Set Next Statement, асинхронный стек вызовов.
  • Данные. Переменные, Watches, Evaluate с completion, значения прямо в редакторе, изменение значений.
  • Подключение. Attach к процессу и отладка тестов.

Solution, а не папка с файлами

Дерево показывает проект так, как его видит сборка. Диалоги правят файлы проекта точечно и не трогают форматирование.

  • Форматы. .sln, .slnx и фильтры .slnf, несколько solution в одной папке.
  • Dependencies. Пакеты с транзитивными, проекты, сборки и анализаторы по каждой целевой платформе.
  • Проект. Новый проект с опциями шаблона, свойства, переименование со всеми ссылками.
  • Сборка и запуск. Build с деревом ошибок, конфигурации по launchSettings.json, окно Services.

Тесты и покрытие в одном окне

xUnit, NUnit, MSTest и TUnit. Поддерживаются и VSTest, и новая Microsoft.Testing.Platform.

  • Запуск. Кнопка у метода и класса, фильтр, повтор упавших, отладка выбранных тестов.
  • Покрытие. Полосы в редакторе, окно по файлам, проценты прямо в дереве проекта.
  • Создание. Тестовый класс для выбранного типа из Alt+Enter.

И всё, что нужно вокруг кода

NuGet

Окно пакетов по solution или проекту, приватные фиды, обновление всех пакетов разом, completion версий в .csproj.

EF Core

Миграции со статусом applied и pending, откат, SQL-скрипт, scaffold. Startup-проект и DbContext подбираются сами.

.NET Monitor

Графики процесса, дамп потоков, снимки кучи с разницей, memory dump с поиском того, кто держит объект.

Endpoints

Маршруты minimal API и контроллеров, HTTP-запрос в один клик, переход к коду.

Форматирование

CSharpier или dotnet format по Ctrl+Alt+L. Опции C# в .editorconfig с подсказками и документацией.

Шаблоны

30 генераторов файлов, 33 live templates, 21 postfix-шаблон, Generate по Alt+Insert.

Чего в плагине нет
  • Razor, Blazor, XAML, F#, VB.NET. Только значки, шаблоны файлов и группировка в дереве.
  • Publish и контейнеры. Нет публикации в папку, IIS, Azure и Docker.
  • Hot Reload. dotnet watch доступен как команда запуска, при отладке изменений на лету нет.
  • Отладка .NET Framework и Mono. Адаптер работает только с .NET Core и .NET 5 и новее.
  • Инспекции ReSharper и профилирование CPU.
Сценарий демо на 10 минут
  1. Открыть папку с solution. Панель Solution, Dependencies по платформам, Show All Files.
  2. Запустить веб-проект из Services. Ссылка на адрес, окно Endpoints, запрос в .http.
  3. Набрать код. Свойство и конструктор серым текстом, лямбда в AddSingleton, expr.notnull.
  4. Alt+Enter. Fix All in Solution, затем Shift+F6 на классе и Ctrl+H.
  5. Отладка. Остановка на исключении, Evaluate, Set Next Statement.
  6. Тесты с покрытием. Unit Tests, Run with Coverage, Rerun Failed.
  7. NuGet. Поиск, установка, Alt+Shift+N.
  8. EF Core. Add Migration, статус миграций, Update Database to Here.
  9. .NET Monitor. Графики, два снимка кучи, memory dump и Who Holds It.

С чего начать

  1. Поставьте инструменты

    Settings, Tools, .NET, .NET Tools. Нужны roslyn-language-server и dotnet-debugger-dap, остальные по желанию.

  2. Откройте папку с solution

    Именно папку, не файл. Панель проекта переключится на Solution. Если solution несколько, IDE спросит, какой загрузить.

  3. Дождитесь загрузки

    Виджет внизу покажет «Roslyn: имя solution». До этого уже работают подсветка, структура и серый текст.
