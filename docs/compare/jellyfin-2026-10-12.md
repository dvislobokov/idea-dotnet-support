# Плагин против Rider на Jellyfin (2026-10-12)

## Сводка

Сравнение плагина **0.1.165** (до исправлений 0.1.166–0.1.167) с **Rider 2026.2.3.1** на Jellyfin, одни и те же места в обеих IDE.
Сырые данные — [`jellyfin-dumps/`](jellyfin-dumps), скрипты — `tools/ui-robot/compare/`. Агент сравнения был остановлен до отчёта;
отчёт собран из дампов, повторно ничего не запускалось.

Главные цифры:

| Что | Плагин | Rider |
|---|---|---|
| Анализ файла до стабильной подсветки, 8 одинаковых файлов, медиана | ≈ 0,6 с (0,09–2,3 с) | ≈ 1,9 с (0,2–4,7 с) |
| Ложные ошибки компилятора на 90 открытых файлах | 17 в 9 файлах (все закрыты в 0.1.166) | 0 |
| Completion после `.` (члены `string`) | ≈ 143 мс | ≈ 209 мс |
| Completion после `new ` / в аргументе | ≈ 556 / 645 мс | ≈ 368 / 367 мс |
| Пунктов Alt+Enter по существу в 25 местах (без «Add a partial part» / «Create test» / навигации) | ≈ 26 | ≈ 95 |
| Пунктов Refactor This в 25 местах | 4–6 одних и тех же | 0–16, по месту |

Топ доработок (полный список — раздел 8):

1. **`var ` при наборе заменяется типом** — `foreach (var preference in ` превратилось в `foreach (ValidUsernameRegex preference in`:
   пробел подтверждает строку списка, выбранную «нечётким» совпадением `V-a-r`, а не ключевое слово `var` (вставка, критично).
2. **`tr` + Tab даёт `true`**, а не блок `try { } catch` — в начале оператора ключевое слово `true` стоит выше `try` (вставка).
3. **«Add missing arms» при уже есть `_`-arm** вписал 27 веток `=> throw new NotImplementedException()` перед `_ => []` — меняет
   поведение кода (Rider в этом случае не предлагает).
4. **Inline variable дублирует конструктор**: `var eventArgs = new UserUpdatedEventArgs(user);` с двумя использованиями → два разных
   объекта (`PublishAsync(new …)` и `Invoke(this, new …)`).
5. **«Wrap in 'using' statement» на не-`IDisposable`** (`new UserUpdatedEventArgs`, `new Dictionary<,>`, `new User(`) — 3 места.
6. **Postfix `.if` после числа** (`oldName.Length > 0.if`) не сработал как postfix — развернулся live template `if` после `0.`.
7. **Нет действий видимости и `partial`** (To private / internal / virtual / abstract, Make … partial) — 7 мест из 25.
8. **Нет Change Signature** — Alt+Enter в 6 местах и Refactor This в 8.
9. **Refactor This почти пустой**: нет Safe Delete (12 мест), Extract Interface / Superclass / Class (10), Pull / Push Members (10),
   Use Base Type Where Possible (8), Move Type to Namespace / File / Folder (6), Inline Method (4); при этом «Introduce Field / Parameter»
   у нас стоит в каждом месте, даже где вводить нечего.
10. **Проверки на null для выражений** (Check expression / variable for null, Assert not null) — 3 места.
11. **Invert 'if' без `else` в середине тела** не предлагается (Rider заворачивает остаток метода в `if` и ставит `else`).
12. **Серый текст guard-блока после других операторов** даёт `return;` там, где Rider (сеть) пишет `throw new ArgumentNullException(nameof(oldName));`;
    после postfix `.null` серого нет совсем.
13. **Completion `Thro`**: ключевого слова `throw` нет в первых 12 строках (у Rider — второе), их занимают статики неимпортированных
    типов (`ObjectDisposedException.ThrowIf`, `Expression.Throw`…).
14. **Introduce variable заменяет одно вхождение из двух** (`dbContext.Users` на соседней строке осталось).
15. **Move type to file** тащит все `using` исходника (лишние), оставляет пустую строку после `{` и ломает отступ `/// <summary>` в исходном файле.

Число строк полного списка по категориям: ложные ошибки 8 (все закрыты в 0.1.166), вставка по Tab 12, completion 5, Alt+Enter 31,
Refactor This 12, рефакторинги в работе 6, скорость 4, стабильность 2 — всего **80**.

## 6. Вставки по Tab

Уже изменено в 0.1.165–0.1.167 (замер до них): второй `break;` после шаблона `switch` больше не подсказывается; серая метка `case`
следует за строкой списка и появляется без лишней клавиши; серый текст, кончающийся именем метода, получает скобки.

| Проба | Rider | Мы | Отличие |
|---|---|---|---|
| t01 `switch` + Tab | `switch (expression\|) { }`, плейсхолдер выделен, список переменных | `switch (\|) { case : … break; default: break; }`, список (`newName`, **`new`**, `oldName`…) | у нас скелет секций; в списке ключевое слово `new` вторым |
| t02 `if` + Tab | `if (expr\|) { }` | `if (\|) { }` + список | равноценно; `new` в списке условия лишний |
| t03 `foreach` + Tab | `foreach (var VARIABLE in COLLECTION\|)` | `foreach (var item in \|)` + список | равноценно |
| t04 `for` + Tab | `for (int i = 0; i < UPPER; i++)` | `for (var i = 0; i < length; i++)` | равноценно |
| t05 `try` + Tab | `catch (Exception e) { Console.WriteLine(e); throw; }` | `catch (Exception e) { throw; }` | у нас чище |
| t06 `prop` + Tab | `public TYPE Type { get; set; }` | `public int MyProperty { get; set; }` | равноценно |
| t07 `ctor` + Tab | пустая строка перед членом, `public UserManager() { \| }` | без пустой строки, `public UserManager(\|) { }` | нет пустой строки между полем и конструктором |
| t08 `tr` + Tab | блок `try { } catch (Exception e)` | **`true`** | в начале оператора выбрано `true`, а не `try` |
| t09 `sw` + Tab | `switch (expression) { }` | шаблон `switch` (как t01) | ок (0.1.161) |

## 7. Рефакторинги в работе

| Действие | Rider | Мы | Отличия |
|---|---|---|---|
| r01 Invert 'if' (`if` без `else` в середине метода) | инвертирует условие, заворачивает **весь остаток метода** в `if`, бросок — в `else` | не предлагается | у нас guard-форма только у последнего оператора |
| r02 To 'switch' expression (секции с несколькими операторами) | не предлагается | не предлагается | одинаково |
| r03 To 'if' statements (`switch (item)` с паттернами) | строка не выбрана роботом | `if (item is IHasSeries hasSeries) … else if …`, `break` убран, отступы верные | у нас корректно |
