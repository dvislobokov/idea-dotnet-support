  - C#: `RoslynCompletionPolicy.priority` + `RoslynCompletionRanking.bonus` (собираются в `RoslynCompletionItems`),
    `ImportCompletion`, `CSharpCaseInsensitiveCompletion`;
  - Go: `GoCompletionWeigher` + `GoAlphabeticalWeigher`, в режиме gopls — `GoplsCompletion`.
- Уже решено в плане:
  - платформенный ML-ranking (`RankingModelProvider`) не используем: признаки считает платформа, офлайн их не повторить, пакет
    `internal`, плагин ранжирования можно выключить;
  - вместо него своя интеграция через `CompletionWeigher` / `PrioritizedLookupElement`;
  - серый текст — дополнительный источник в `CSharpGhostTextProvider` / `GoInlineIdiomsProvider`;
  - уровни: L1 ранжирование → L2 n-граммы Kneser–Ney (глобальная модель ⊕ проект ⊕ кэш правок) → L3 трансформер только по
    критериям плана;
  - Go идёт первым: ожидаемые типы в go-psi уже есть;
  - C# до шага 11 учится на кандидатах Roslyn (`roslyndump completion`), после шага 11c `CSHARP_PSI_MIGRATION.md` переобучается.
