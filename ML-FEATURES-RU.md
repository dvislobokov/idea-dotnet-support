# ML-функции .NET-плагина — что есть, где включается, как проверить

Состояние на 2026-10-08 (0.1.138). Все функции имеют выключатель; по умолчанию включены. Ничего из списка не проверялось
вживую в IDE — сервер без UI; это чеклист для живой проверки. Сценарии с маркерами лежат в `debug-playground/Console/Editor/`
(`Mapping.cs`, `ImportType.cs`, README там же).

## Сборки
- Обычная сборка (`bash gradlew buildPlugin`, ~10 МБ): только PSI-функции — маппинг, память выбора, выбор `using` по статистике
  (последний работает, если рядом есть `ml-models/csharp/cs-imports-e20.cml` или задан каталог моделей).
- ML-сборка (`bash gradlew buildPlugin -PmlEnabled=true [-Pml.big=true]` → `build/distributions/idea-dotnet-support-<версия>-ml.zip`,
  ~70 МБ, с 50 M — 120 МБ): плюс серый текст от нашей сети (31 M, с `-Pml.big` ещё 50 M), ранкер списка (n-gram e15-a + GBDT e19)
  и статистика импортов в jar; нативные ядра для Linux/Windows/macOS внутри `lib/ml-core.jar`. Собирается и на сервере.

## Где настройки
- **Settings | .NET | ML completion** (`CSharpMlConfigurable`, ML-сборка): ранкер вкл/выкл, метка « ML» (выкл.), серый текст
  вкл/выкл, большая модель, пороги (0.7 общий, 0.5 после `.`/`?.`/`::`/`->`, 0.25 на пустой строке), одиночные закрыватели,
  оценка текста строк, подсказки внутри строковых литералов (вкл.) и комментариев (выкл.), отладочный лог, вес памяти выбора (0.3),
  строка состояния сети (модель, потоки, ядра, показано/принято), каталог моделей.
- **Settings | .NET → Behavior** (обычная сборка тоже): «Offer to copy members…» (маппинг), «Remember what I choose in the list»
  + кнопка Forget the Choices, «Order namespaces by corpus statistics».

## Что проверить
1. **Серый текст** (ML-сборка). Открыть `.cs`: в логе категория `ml` — модель и ядра. `Console.Wri` → `teLine("Hello World!");`;
   `_log.Error("failed to ` — продолжение внутри строки показывается; внутри `//` и `///` — нет. После `obj.` порог 0.5;
   после Enter на пустой строке 0.25. Tab принимает только серый текст. Первая подсказка в только что открытом файле — быстро
   (prefill при открытии, ~6 мс вместо холодного старта).
2. **Ранкер** (ML-сборка). Список без суффикса « ML» (включается в настройках); порядок после точки отличается от правил;
   в строке состояния ранкер «200 trees» (GBDT e19).
3. **Маппинг**. `var dto = new UserDto { ⟨⟩ };` при `user` подходящего типа: строки `Name = user.Name,` с хвостом « map» и жирная
   «Map all remaining members from user»; `required` первыми, `init`-only только в инициализаторах, уже заданные пропущены.
   На строке после `dto.Name = user.Name;` — строки-присваивания.
4. **Память выбора**. Выбрать один элемент 3 раза в похожем контексте — поднимается (обычная сборка — внутри группы приоритета,
   ML — бонус к скору). Forget the Choices обнуляет; хранится в workspace-файле проекта.
5. **Выбор `using`**. Неразрешённый `JObject` → квик-фикс предлагает `Newtonsoft.Json.Linq` первым; `JsonSerializer` → `System.Text.Json`;
   `Task` → `System.Threading.Tasks`; `Color` → `UnityEngine`, но при `using System.Drawing.Imaging;` — `System.Drawing`.
   В списке неимпортированных типов тот же порядок внутри группы.

## Если что-то не так
- Серого текста нет: строка состояния на странице ML completion — модель не загрузилась (нет файлов в `ml/csharp/` jar или в
  каталоге моделей); ядра не загрузились → scalar, медленнее, но работает (антивирус/`%TEMP%` на Windows).
- Подсказки внутри строк мешают — выключить «Suggest inside string literals».
- Ранкер молчит: схема `e19-rank-gbdt.cml` должна совпадать с `CSharpMlFeatures` (ошибка в логе «trained for another feature set»).
